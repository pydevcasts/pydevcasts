# 💫 About Me

🔬 **ML Researcher in Medical Data Science** | M.Sc. Artificial Intelligence & Robotics

I build **leakage-aware, interpretable machine learning pipelines** for
clinical and multi-omics data, with a focus on **oncology applications**.

## 🔬 Research Interests

- **Statistical Machine Learning** — model evaluation, nested cross-validation, leakage control
- **Multi-omics Data Integration** — late fusion of clinical, transcriptomic, and genomic data
- **Interpretable ML in Oncology** — SHAP, feature stability, biomarker discovery
- **External Validation & Generalizability** — cross-cohort transfer, calibration
